# Guest QR ordering

Each table carries a printed QR code. Scanning it opens the guest menu in
the phone's browser; there is no app to install. The QR encodes the table
number and a rotating token, so a photographed code stops working when the
token rotates.

Guests add items to a shared cart. Everyone who scans the same table code
sees the same cart, which is how a group coordinates one order. When the
guests place the order, it lands on the kitchen display as an online order
and is attached to the table's tab. Guests pay at the counter in this
configuration; online payment is not wired up.

The guest page is read-only after the order is placed: guests can watch
their ticket states move from new to ready, but they cannot edit a placed
order. Corrections go through the staff.
